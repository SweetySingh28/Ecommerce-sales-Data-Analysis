# E-Commerce Sales Data Analysis

**Author:** Sweety Singh  
**Institute:** RV Institute of Technology  
**Course:** Data Analytics

## Project Overview
This project analyses an e-commerce sales dataset using Python. The aim is to understand sales, profit, customer orders, category performance, regional performance and monthly sales trends.

## Objectives
- Clean and inspect sales data
- Calculate key business KPIs
- Analyse sales by category and region
- Identify high-performing products
- Study monthly sales trends
- Present insights using visualizations

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Files
- `ecommerce_sales.csv` — project dataset
- `ecommerce_analysis.py` — analysis code
- `requirements.txt` — required Python libraries
- `README.md` — project documentation

## How to Run
1. Install Python.
2. Run `pip install -r requirements.txt`.
3. Open/run `ecommerce_analysis.py` or copy the code into Jupyter Notebook.
4. Keep `ecommerce_sales.csv` in the same folder.

## Note
The dataset is a synthetic educational dataset created for this student project. It is intended for demonstrating data analytics techniques.
